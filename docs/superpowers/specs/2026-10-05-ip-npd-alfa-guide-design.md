# Design: Guide «ИП на НПД» (Альфа → Точка) (pyBot)

**Date:** 2026-10-05  
**Status:** Approved and implemented (2026-10-06).

## Goal

Понятный пошаговый мастер: человек открывает **ИП на НПД** через Альфу, затем идёт в **Точку** за расчётным счётом и эквайрингом — без ложных обещаний «вообще без налогов» и «примут все банки».

## Locked product decisions (consistency pass)

| Тема | Было в разговоре | Итог после проверки |
|------|------------------|---------------------|
| Банк | Сначала Точка, потом Альфа | **Альфа — регистрация ИП на НПД**; **Точка — расчётный счёт / эквайринг** (после получения ИП) |
| Регистрация | «Через Госуслуги сами» | **Основной путь — заявка в Альфу под ключ**; Госуслуги/ФНС — запасной DIY |
| Порядок | «Сначала самозанятый, потом ИП» | **Не обязательно**. ИП может встать на НПД напрямую ([ФНС / npd.nalog.ru](https://npd.nalog.ru/)) |
| «Бесплатно» | «Ничего не платить» | **Без госпошлины** при электронной подаче; **налог с дохода 4%/6%** остаётся |
| Бланк Р21001 | Как будто обязателен пользователю | Альфа готовит пакет сама; бумажный Р21001 в боте — опционально |
| Что бот делает | Подаёт за человека | **Только ведёт**: тексты, ссылки, кнопки «Сделал → дальше» |

## Main user path (v1 master)

1. **Зачем это**  
   ИП нужен для статуса и работы с банками; НПД — простой налог с дохода (4% физлица / 6% юрлица и ИП).  
   Лимит дохода по НПД — 2,4 млн ₽/год; нельзя нанимать сотрудников по трудовому договору и вести запрещённые виды деятельности.

2. **Зарегистрировать ИП на НПД через Альфа‑Банк**  
   Ссылка (партнёрская): `https://alfabank.sale/sme/agent/start/ip-npd/`  
   (полный UTM — в config).  
   Нужны: паспорт, СНИЛС, лучше ИНН.  
   Онлайн — без госпошлины 800 ₽. Ждём подтверждение от ФНС (обычно до нескольких рабочих дней).  
   В анкете/сопровождении банка явно выбрать/подтвердить **НПД**, не перепутать с УСН.  
   **Важно для UX:** Альфа по ходу заявки почти наверняка предложит **свой** расчётный счёт.  
   По закону счёт в банке регистрации **не обязателен**, счетов может быть несколько.  
   В мастере честно сказать: «счёт можно открыть в Точке на следующем шаге; предложение Альфы — по желанию (можно оба счёта)».

3. **Открыть счёт и эквайринг в Точке**  
   Когда статус ИП уже есть — открыть расчётный счёт в Точке; при необходимости подключить эквайринг (СБП/QR, интернет, торговый).  
   Дисклеймер: банк может отказать; это не «примут всех».  
   Для новых ИП часто есть льготный тариф — актуальные условия на сайте Точки.

4. **Проверить НПД**  
   В «Мой налог» / кабинете убедиться, что режим НПД активен для ИП; чеки клиентам — через «Мой налог».

## Secondary path (коротко, не основной)

«Хочу сам через Госуслуги / ФНС»:
- Самозанятость: Госуслуги или [Мой налог](https://npd.nalog.ru/).
- ИП: [Онлайн-регистрация бизнеса ФНС](https://service.nalog.ru/gosreg/index.html) (часто Госключ / ЭП).
- Затем НПД как ИП в «Мой налог».
- Потом счёт в банке.

Этот путь длиннее — в UI кнопка «Сделать самому», не главный экран.

## Copy rules (anti-inconsistency)

- Не писать: «вообще ничего не платите», «Точка/Альфа примет всех».
- Писать: «регистрация онлайн без госпошлины», «налог только с дохода 4% или 6%», «если дохода нет — НПД не начисляется».
- Всегда: «Это инструкция-помощник, не юридическая консультация; актуальные условия — на сайте банка и ФНС».

## Non-goals (v1)

- Автоподача документов ботом.
- Заполнение Р21001 за пользователя.
- Сравнение всех банков.
- Ведение бухгалтерии / сдача отчётов.

## Risks found in self-review

1. **Landing Альфа «ИП на НПД» vs общие страницы «открыть ИП»** — на общих страницах банк часто готовит ещё и УСН. В мастере явно: выбрать/подтвердить **НПД**, не перепутать с УСН.  
2. **Партнёрская ссылка** с UTM — хранить в `.env` / config, не хардкодить километровый URL в UI.  
3. **Альфа предложит свой счёт** при регистрации — не баг маршрута «потом Точка», но нужна явная фраза в UI (см. шаг 2), иначе человек запутается.  
4. **Два банка = два онбординга** — чуть длиннее путь; зато честное разделение: Альфа = регистрация, Точка = РКО/эквайринг.  
5. **Официальные бланки** остаются отдельной фичей; гид на v1 не обязан слать Р21001.

## Success

Новый пользователь понимает: Альфа = открыть ИП на НПД; Точка = счёт и эквайринг; налог 4%/6% с дохода — без ощущения «обманули про бесплатность».
